# 🧠 AI Trend Hunter & Viral Thread Architect (شکارچی ترندهای هوش مصنوعی و معمار ترد)

سامانه هوشمند و ترمینال رصد لحظه‌ای ترندهای هوش مصنوعی، مدل‌های پرچمدار، مقالات دیلی پیپرز Hugging Face، ریپازیتوری‌های داغ GitHub و موتور تولید خودکار رشته‌توییت‌های وایرال توییتر/X و پست‌های تلگرام و لینکدین.

---

## 🌟 امکانات کلیدی

1. **🔥 رادار زنده ترندهای AI:**
   - فچ مستقیم و خودکار مقالات برگزیده روز از Hugging Face Daily Papers API.
   - رصد لحظه‌ای مخازن ترند GitHub با بیشترین سرعت رشد ستاره در حوزه‌های LLM، ایجنت‌های خودکار و بینایی ماشین.
   - محاسبه امتیاز پتانسیل وایرال شدن (Virality Score از ۰ تا ۱۰۰).

2. **🧵 استودیو شبیه‌ساز ترد توییتر / X (Twitter/X Thread Simulator):**
   - پیش‌نمایش زنده رشته‌توییت به سبک واقعی توییتر با آواتار، نشانگر وریفای آبی، خط اتصال عمودی بین توییت‌ها و دکمه‌های کپی و ارسال مستقیم.
   - تولید هوشمند توییت قلاب (Hook)، تشریح درد مسئله، راهکار فنی، بنچمارک‌ها، راهنمای تست و کال تو اکشن (CTA).
   - تولید همزمان پست با فرمت کانال VIP تلگرام و پست رسمی لینکدین.

3. **📸 استودیو کارت‌ساز تصویری وایرال (16:9 Visual Card Studio):**
   - تولید خودکار کاور گرافیکی ۱۶:۹ با استاندارد توییتر (1200x675) با تم دارک نئونی، بج‌های وایرال، نکات کلیدی و واتر‌مارک رسمی جهت افزایش ۵ برابری تعامل.

4. **✨ ساخت ترد دلخواه با هر موضوع یا پرامپت:**
   - امکان تایپ هر موضوع دلخواه توسط کاربر و تولید فوری پکیج کامل رشته‌توییت.

---

## 🚀 نحوه راه‌اندازی بک‌اند

```bash
# اجرای سرور بک‌اند
python3 trendhunter_server.py
```
سرور به طور خودکار روی پورت ۸۸۹۲ بالا می‌آید و اندپوینت‌های زیر را ارائه می‌دهد:
- `GET /api/trends`: لیست ترندهای داغ با فیلتر دسته‌بندی
- `POST /api/generate`: تولید هوشمند رشته‌توییت و پست‌ها
- `GET /api/stats`: خلاصه آمار و وضعیت رادار
- `GET /api/health`: بررسی سلامت سرویس
